# 발췌기 연결 (DL-excerpt)

드림랜드(DreamLand)에서 보고 있는 채팅을 [발췌기](https://romantic-lamb.github.io/excerptourstory/)로 바로 보내는 확장입니다.
파일로 내보내지 않아도 발췌기의 메시지 고르기 창이 바로 열리고, 고른 메시지를 칸으로 가져와 이미지 · PDF · HTML 발췌본으로 만들 수 있습니다.

## 설치

드림랜드 › 확장 › **URL로 설치**에 아래 주소를 넣습니다.

```
https://github.com/romantic-lamb/DL-excerpt/blob/main/DL-excerpt.js
```

**업데이트는 자동입니다.** 설치하는 `DL-excerpt.js`는 껍데기이고, 드림랜드를 켤 때마다 GitHub에서 최신 본체(`core.js`)를 받아 실행합니다.
GitHub에 닿지 않으면 마지막으로 받아 둔 본체를 쓰고, 새 본체가 실행되지 않으면 이전 본체로 돌아갑니다.

## 쓰는 법

- **메시지 메뉴 › 발췌기로 보내기**: 그 메시지를 골라 둔 채로 발췌기가 열립니다. 발췌기에서 범위를 더 고르고 `고른 메시지 가져오기`를 누르세요.
- **장면 패널 › 발췌기**
  - 보낼 글: 번역이 있으면 번역문 / 늘 원문
  - 숨긴 메시지 · 시스템 메시지도 보낼지
  - 미리 골라 두기: 최근 10 · 20 · 50개
  - `파일로 내려받기`: `.jsonl`로 받아 발췌기의 `채팅 파일에서 가져오기`로 엽니다.
- **`/excerpt 20`**: 최근 20개를 골라 둔 채로 발췌기를 엽니다.

## 개인정보

채팅은 서버를 거치지 않습니다.
- 짧으면 압축해서 발췌기 주소의 `#` 뒤에 담습니다. `#` 뒤는 서버로 보내지지 않고, 발췌기는 읽자마자 주소에서 지웁니다.
- 길면 드림랜드가 연 발췌기 창에만 `postMessage`로 직접 건넵니다.

## 알아 둘 점

- 드림랜드 앱(iOS)에서는 긴 채팅을 바로 보낼 수 없어 `파일로 내려받기`를 써야 합니다.
- 창이 열리지 않으면 브라우저의 팝업 차단을 확인해 주세요.
