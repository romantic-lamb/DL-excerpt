# 발췌기 연결 (DL-excerpt)

드림랜드(DreamLand) 화면 안에서 [발췌기](https://github.com/romantic-lamb/excerptourstory)를 열고, 보고 있는 채팅을 바로 넣어 이미지 · PDF · HTML 발췌본으로 만드는 확장입니다.
파일로 내보내거나 다른 창으로 옮길 필요 없이, 발췌기의 메시지 고르기 창이 드림랜드 안에서 바로 열립니다.

## 설치

드림랜드 › 확장 › **URL로 설치**에 아래 주소를 넣습니다.

```
https://github.com/romantic-lamb/DL-excerpt/blob/main/DL-excerpt.js
```

**업데이트는 자동입니다.** 설치하는 `DL-excerpt.js`는 껍데기이고, 드림랜드를 켤 때마다 GitHub에서 최신 본체(`core.js`)를 받아 실행합니다.
발췌기 페이지도 열 때마다 최신본을 받아 오고, 받지 못하면 마지막으로 받아 둔 것을 씁니다.

## 쓰는 법

- **메시지 메뉴 › 발췌기로 보내기**: 그 메시지를 골라 둔 채로 발췌기가 열립니다. 범위를 더 고르고 `고른 메시지 가져오기`를 누르세요.
- **장면 패널 › 발췌기**
  - 보낼 글: 번역이 있으면 번역문 / 늘 원문
  - 숨긴 메시지 · 시스템 메시지도 보낼지
  - 미리 골라 두기: 최근 10 · 20 · 50개
  - `보내지 않고 열기`: 채팅을 넣지 않고 발췌기만 엽니다.
- **글 골라 발췌하기**: 채팅에서 글을 드래그해 고르면 작은 단추가 뜹니다.
  - `발췌하기`: 고른 글을 화자별로 나눠 발췌기 칸으로 넣고 발췌기를 엽니다. 여러 메시지에 걸쳐 골라도 메시지마다 나뉩니다.
  - `담기`: 열지 않고 넣어 두기만 합니다. 여러 곳을 차례로 모을 때 씁니다.
  - 장면 패널에서 끌 수 있습니다.
- **`/excerpt 20`**: 최근 20개를 골라 둔 채로 엽니다.
- 위쪽 막대의 `지금 채팅 다시 넣기`로 다른 채팅이나 새 메시지를 더 넣을 수 있습니다. `x`로 닫아도 쓰던 내용은 남아 있다가 다시 열면 이어집니다.
- 컴퓨터처럼 넓은 화면에서는 가운데 뜬 창으로 열리고, 창 바깥을 누르면 닫힙니다. 막대의 크기 단추로 화면에 꽉 채울 수 있습니다. 휴대폰에서는 늘 꽉 찬 화면입니다.

채팅은 드림랜드 안에서 발췌기로 바로 건너가고, 바깥 사이트나 서버를 거치지 않습니다.
